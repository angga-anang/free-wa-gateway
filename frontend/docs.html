Dokumentasi API

Untuk developer yang ingin menghubungkan aplikasi baru ke gateway ini.

Direkomendasikan untuk integrasi baru. Autentikasi pakai header Authorization: Bearer <API_KEY>. Setiap pesan yang dikirim otomatis masuk antrean dengan jeda humanized 2-5 detik per perangkat, retry otomatis 3x, dan tercatat penuh di halaman Riwayat Pesan.

Meniru kontrak API gateway WA versi lama - cocok untuk aplikasi lama yang tidak bisa/sulit diubah kodenya. Autentikasi pakai header x-api-key: <API_KEY>. Kalau server Anda hanya punya satu perangkat terhubung, semua endpoint di bawah otomatis memakainya.
